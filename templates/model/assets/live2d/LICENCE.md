# Hiyori

Live2D's own sample model, from `Samples/Resources/Hiyori` of the Cubism SDK
for Native. Not ours: it is distributed by Live2D Inc. under their
sample-material terms, which permit use with the Cubism SDK and do not make it
yours to relicense.

It is here so `nx.py new <name> -t live2d/model` produces something that runs.
If you are shipping, replace it with your own export and delete this directory.
